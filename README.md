# ✨ Features

- 🌍 170+ Supported Currencies
- 💹 Live Exchange Rates
- 🚩 Country Flags
- 🔄 One Click Currency Swap
- 📋 Copy Conversion Result
- 🌙 Dark / Light Theme
- 📱 Fully Responsive Design
- ⚡ Fast & Lightweight
- 🔄 Auto Update on Currency Change
- 🎯 Clean & Modern UI

---

# 🛠 Tech Stack

- HTML5
- CSS3
- JavaScript (ES6)
- Currency API
- Flags API
